# Resource Ledger / 資源台帳

**日本語** | [English](README.en.md)

RimWorld 1.7の物資の在庫、増減と原因を確認するMODです。武器・装備・梱包済み家具やMOD追加物資にも対応します。

## 導入

RimWorld 1.7と1.7対応のHarmonyが必要です。[Releases](https://github.com/pengin0503/rimworld-ResourceLedger/releases) の最新 `ResourceLedger_<版>_Mod.zip` を展開し、`ResourceLedger` フォルダを `RimWorld/Mods` に置きます。CoreとHarmonyの後に有効化し、再起動してください。`Source.zip` はゲームへの導入用ではありません。

既存セーブに追加でき、記録は導入後から始まります。最初に観測した物資は開始残高として扱い、記録のない過去は0で埋めません。変更前にセーブをバックアップしてください。

## 使い方

画面下部の台帳アイコンから開きます。物資の名前・カテゴリ・追加元MODなどで絞り込み、最大6種類を比較できます。在庫は棒、増加・減少・純増減は線で表示します。対象はマップ全体、保管場所、指定保管場所、全拠点から選べ、個数・栄養量・基準市場価値を切り替えられます。

原因別の内訳、行動明細、保管場所、通知、CSV出力を利用できます。通知は在庫の上下限、減少量・減少率、推定残日数などを設定できます。CSVはユーザーデータフォルダ内の `ResourceLedgerExports` に保存されます。

## 対象と注意

所有する可視の地面・棚・対応コンテナ内の物資と、所属ポーンの所持・運搬・装備が対象です。敵や訪問者の持ち物、未発見の品、死体、設置済み建物などは含みません。記録は種類単位で、品質や材質別には分けません。

原因を取得できない差分は「原因不明」として表示されます。他MOD固有の処理をすべて分類できる保証はありません。記録間隔や履歴の保持期間は設定可能です。原因記録ではマップ上の物資を走査するため、大規模コロニーのTPSへの影響は未確認です。負荷が気になる場合は「運搬・マップ間移動も記録する」を無効にできます。
