原因別記録の集計処理を軽量化しました。

- 既に初期記録がある範囲では、その確認のために在庫を再集計しません。
- マップ全体の集計では、読み取り時に計算した合計を再利用します。
- 消費材料がない操作では、消費材料の範囲別集計のために在庫全体を走査しません。

操作前後のマップ走査は引き続き行います。実ゲームでのTPSやMOD構成ごとの改善幅は未測定です。

**ゲーム用は `ResourceLedger_0.3.1_Mod.zip` です。** 展開した `ResourceLedger` フォルダーを `RimWorld/Mods` に配置し、Harmonyの1.7対応版と一緒に有効化してください。既存の履歴は引き続き使用できます。
