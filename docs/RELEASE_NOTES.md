在庫・増加・減少・純増減を大きな数値で表示し、在庫の棒グラフと増減の折れ線を同時に確認できるようにしました。左右の軸を独立に調整し、集計間隔と正確な値を表示します。

- 全種類の所有アイテムを自動追跡。武器・衣服・装備品・梱包済み家具、MOD追加品にも対応。
- 在庫あり／変動あり／全履歴、名前・カテゴリ・追加元MODで絞り込み。
- 専用アイコン、物資のアイコン、大きな数値欄、色・符号・線種による識別。
- 原因別集計・行動明細・所在・通知・CSVを維持。
- 記録開始前の空白を抑え、欠測をまたぐ線を描画しない。日別集計で未分類差分を保持。
- 保存データを圧縮し、0.1.0の履歴も読み込み可能。
- GitHub CIでコアのビルド・テスト、翻訳／XML、ビルド指紋、配布ZIPを検証。

**ゲーム用は `ResourceLedger_0.2.0_Mod.zip` です。** 展開した `ResourceLedger` フォルダーを `RimWorld/Mods` に配置し、Harmonyの1.7対応版と一緒に有効化してください。0.1.0からは同じフォルダーを置き換えます。
