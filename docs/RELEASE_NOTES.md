レビューで見つかった7件の不具合を修正しました。0.2.0の6系統の不具合に加え、配布文書の不足も修正しています。

- #1 保存データのnull・重複時刻・履歴キー不一致・非有限数値を拒否し、元データを読み取り専用で保全。
- #2 日次集約でも未記録区間を欠測として保持。
- #3 コンテナ読み取り失敗時は現在庫・予測を不明扱いにし、回復区間を架空の増減にしない。全拠点結合にも反映。
- #4 倉庫上のポーンの携行品・装備品を保管在庫に加算しない。
- #5 保管範囲内の同一物資の生産・消費を相殺せず、具体的な増加数・減少数を保持。
- #6 記録のない期間のCSVに架空の在庫0行を出力しない。
- #7 ゲーム用ZIPにもレビュー記録REVIEW.mdを同梱し、文書リンクを有効にする。

全種類の自動追跡、在庫の棒グラフと増減の折れ線、独立した左右目盛り、強調表示、アイコン、原因別内訳、絞り込み等は引き続き利用できます。

**ゲーム用は `ResourceLedger_0.2.2_Mod.zip` です。** 展開した `ResourceLedger` フォルダーを `RimWorld/Mods` に配置し、Harmonyの1.7対応版と一緒に有効化してください。0.1.0・0.2.0・0.2.1からは同じフォルダーを置き換えます。既存の保存形式に対応しますが、旧版ですでに失われた内訳は復元できません。

RimWorld 1.7専用。実DLL参照ビルド、84件のC#テスト（70コア＋14 API契約）、5件のPythonテストと配布物検証を実行しています。CIはゲームDLLなしで70件のコアテストと配布物を検証します。

ゲーム内での画面表示・通常プレイ・実セーブ更新は未確認のため、プレリリースです。検証範囲と制限はREADME.md・VALIDATION.md・REVIEW.mdを参照してください。
